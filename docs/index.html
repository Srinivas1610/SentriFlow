The UPI Fraud Problem Space

Why traditional cloud-only fraud detection systems fail to protect instant payments.

Voice Call Coercion

Scammers guide victims over phone calls to input UPI PINs. SentriFlow intercepts active unknown calls in real time to block checkouts.

SMS Phishing Scams

Malicious links trigger automated UPI requests. Our on-device TFLite TinyBERT model runs NLP classification locally to score text threats.

Mule Accounts

Fraud syndicates cash out funds rapidly. SentriFlow cross-checks transaction recipients against high-velocity and trust scores.

Latency & Cost Bottleneck

Cloud round-trips take 2-3 seconds, ruining checkout flow. We utilize a local C++ rule hot-loop taking only 200ns, keeping cloud review < 0.3%.

The 3-Tier Cascading Threat Engine

How SentriFlow partitions workload between edge devices and the cloud for optimized defense.

Tier 1

On-Device Heuristics

Latency: 200ns | Cost: $0.00

Runs deterministically on the client device. Checks active call status, new recipient limits, and community flags to construct a baseline risk rating instantly.

  • Checks active unknown call status
  • Checks community flags on recipient
  • Checks amount / new recipient limit
Tier 2

On-Device NLP (TinyBERT)

Latency: 50ms | Cost: $0.00

Runs background NLP classification on incoming SMS. Detects phishing link messages, OTP theft prompts, and bank spoofing alerts without exposing private data.

  • Local model inference
  • Preserves user privacy (no PII leak)
  • Produces a local SMS phishing risk score
Tier 3

Cloud LLM Escalation

Latency: 2.0s | Cost: Premium

If Tier 1 gives a warning risk score (50-75) AND Tier 2 indicates an uncertain SMS threat (0.40-0.65 score), it escalates a PII-stripped version to Amazon Bedrock GPT-OSS 120B for a second opinion.

  • Asynchronous audit thread
  • Restricted to < 0.3% of traffic
  • Generates natural explanations for UI

Developer Quickstart

        
Get the benchmark and stress-testing suite running locally in minutes.

      


      

        

          

          

          

          PowerShell - local dev

git clone https://github.com/Srinivas1610/SentriFlow.git

          
cd SentriFlow/sentriflow-bench

          

          
# Install requirements

          
pip install -r requirements.txt

          

          
# Build C++ native module and start telemetry streaming server

          
./run_bench.ps1
